# P6f 購入不能候補の走査是正

## 変更内容

従来の`PortfolioSimulator.run`は、順位付けした候補を空き枠数で先に切り、その後で
100株単元を購入できるか判定していました。上位候補が1枠の目標金額を超えると、購入できなくても
候補リスト上の枠を消費し、後続の購入可能候補を確認しませんでした。

修正後は候補を順位順に確認し、実際に買い注文が成立した件数だけを空き枠へ数えます。
同日損切りとなった買い注文も成立件数へ数えるため、1日の新規約定数は従来どおり開始時の空き枠以内です。
現金非負、最大保有数、100株単元の制約は維持します。

## 回帰テスト

最大1銘柄、元本1,000円、100株単元の合成データを追加しました。順位1位の銘柄は最小2,000円で
購入不能、順位2位は1株5円で購入可能です。修正後は順位2位を200株買い、最終資産1,200円、
最大保有数1、現金非負になることを確認します。

```powershell
python -m unittest tests.test_backtest_wfa
```

12件が成功しました。全体の`python scripts/verify_project.py`でも125件が成功しています。
