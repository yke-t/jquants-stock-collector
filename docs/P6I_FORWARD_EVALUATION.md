## 実行

```powershell
python -m src.forward_evaluation --db stock_data.db
```

任意の日付で観測を止める場合は`--end YYYY-MM-DD`、ローカルJSONも保存する場合は
`--output <path>`を指定します。SQLiteは読み取り専用で、外部書き込みや注文は行いません。

252取引日に達すると評価を固定し、それ以後の価格は同じプロトコルの成績へ含めません。
21、63、126取引日は中間観測点ですが、合否や設定変更には使いません。
