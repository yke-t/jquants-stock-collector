# ポートフォリオ・ウォークフォワード検証仕様

`src/backtest_wfa.py`は、旧バックテストの先読み約定、株式分割前後の価格基準、資金制約、
取引コスト、損益集計の問題を是正する読み取り専用の検証エンジンです。

## 実行

```powershell
python -m src.backtest_wfa --start 2016-01-01 --splits 5
```

主な引数は`--end`、`--initial-capital`、`--max-positions`、`--lot-size`、
`--commission-bps`、`--slippage-bps`です。結果を保存しない確認には`--no-save`を使います。
SQLiteはURIの`mode=ro`で開くため、この処理はDBを更新しません。

## 約定規則

- シグナルは各取引日の終値確定後に生成し、翌取引日の始値でのみ新規約定します。
- 始値が損切り／トレーリング水準を下回るギャップでは、到達不能な逆指値ではなく始値で決済します。
- 日中の高値は翌取引日以降のトレーリング判定に反映します。同一日の日中高値を先に見てから、
  その日の安値で決済する順序は採用しません。
- 新規約定日の損切りだけは保守的に同日の安値で判定します。
- 各WFA区間の最終取引日は終値で強制決済し、未実現損益を消失させません。
- 買いと売りの双方にスリッページと手数料を適用します。

## 株式数基準とデータ品質

`src/price_basis.py`がJ-Quantsの明示的な`adjustmentfactor`をイベント係数として使い、
OHLCを最新の株式数基準へそろえます。係数を推測することはありません。係数が不正、OHLCが不正、
または係数のない前日比30%以上の断絶がある銘柄は検証対象から銘柄単位で除外します。
除外数と明示的な調整イベント数は`wfa_summary.json`の`data_quality`に記録します。

## 資金と集計

- 現金残高、最大保有銘柄数、売買単位を注文前に制約します。
- 同日の候補は押し目率と銘柄コードで決定論的に順位付けします。
- 日次の現金と時価を合算して資産曲線を作り、総収益率、CAGR、最大ドローダウン、
  年率ボラティリティ、ゼロ金利Sharpe、勝率を計算します。
- 取引リターンの単純加算や、平均取引リターンからの擬似年率換算は行いません。
- 既存目標のCAGR 15%以上、最大ドローダウン-20%以上に対する合否を結果JSONへ記録します。

## ウォークフォワード方式

取引日を`分割数 + 1`個の連続ブロックへ分けます。学習期間は先頭から拡大し、直後の1ブロックを
重複しないテスト期間として使います。固定された小さなパラメータ候補だけを学習期間で選び、
各テスト区間の純資産日次リターンを時系列順に連結してアウト・オブ・サンプル成績を算出します。

## 既知の制約

- 銘柄区分は`fundamentals.scalecat`の現在値を使うため、過去時点の指数構成を再現できず、
  サバイバーシップ・バイアスが残ります。
- 指値板、出来高に対する注文参加率、ストップ安での約定不能、税金はモデル化していません。
- 調整係数は取得した価格履歴の範囲に存在する明示値だけを使います。
- 本結果は検証用であり、将来収益や実運用の約定を保証しません。

## 出力

`reports/wfa/`に次を出力します。このディレクトリはGit管理対象外です。

- `wfa_summary.json`: 集計値、実行条件、方法論、データ品質
- `wfa_folds.csv`: 区間、選択パラメータ、学習／テスト成績
- `wfa_equity.csv`: 連結したアウト・オブ・サンプル資産曲線
- `wfa_trades.csv`: コスト控除後のアウト・オブ・サンプル取引
